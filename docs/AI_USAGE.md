# Uso de IA e validação

Esta evolução do projeto foi implementada com assistência de IA (Codex). Isso inclui código, testes, documentação e organização do repositório. Não representa experiência profissional nem certifica domínio pessoal do mantenedor.

## Como revisar o resultado

1. Execute os comandos de teste do README e leia pelo menos um teste de regra de negócio.
2. Execute um fluxo válido e um inválido pela interface.
3. Escolha uma pequena alteração, explique o comportamento esperado e implemente-a.
4. Confira o diff e acrescente um teste que falharia sem sua mudança.
5. Registre o resultado em uma issue ou pull request com datas reais.

## O que foi verificado nesta entrega

Testes automatizados e fluxos no navegador local. Screenshots em docs/preview.png foram capturadas da aplicação em execução.

Os workflows no GitHub executam verificações adicionais. O status atual é a execução do Actions, não uma promessa de ausência de defeitos. Consulte as limitações do README.

## Exercício para entrevista

Explique o problema resolvido, a regra mais importante, o caminho da requisição e um teste que impede regressão. Se ainda não conseguir explicar uma parte, registre-a como ponto de estudo antes de apresentá-la como competência.
